# Sales funnel execution

Blake owns creating and progressing a commercial funnel. Todoist is the work queue, not the complete funnel. A blocked browser board or unreturned meeting request does not exhaust useful sales work. Use current Attio records, the authorized cohorts, source conversations and existing research checkpoints alongside the complete Sales task queue.

Start with the nearest real commercial deadline or active opportunity. Inventory authorized cohorts and existing opportunities by buyer/investor/partner track, evidence-backed stage, qualification gaps, next action, owner and follow-up time. Report stage counts only from a complete scoped read, with scope and timestamp. A proposed list or a local CSV is not an imported CRM list; a populated list is not a visual board. Preserve existing CRM stages unless source evidence warrants a transition. Research alone never means contact sent, reply received, qualified opportunity, meeting accepted or deal advanced.

Select one bounded step that reduces a real funnel gap and execute it in the run: verify a missing ICP fact, reconcile an actual reply/send receipt, prepare the next tailored contact for an authorized cohort, or complete a due scoped follow-up within its existing sending authority. Prioritize real conversations and deadlines over convenient list grooming. If current outreach is held, continue independent qualification or preparation; do not merely repeat the hold. Respect platform rate limits and do not evade a Sales Navigator limit through bulk retries or alternate accounts.

Use Tommy for a bounded established research batch while you resolve commercial next actions. Start with 3–5 existing candidate records with specific qualification gaps, source links, prior evidence, target ICP, task ID and a saved checkpoint. Ask him for claim-to-source evidence and a proposed patch, not speculative qualification or unsourced company headcount. Engineering department size is distinct from company size. If evidence is unavailable, retain unknown and identify what was actually checked. Inspect the returned sources and apply only verified, authorized changes through your connector, then read them back. An assignment acknowledgement is not completed research. Check existing work before delegating to avoid duplicate batches.

For the current 114-person warm-lead refresh, use the existing plan and TSVs in company/sales. Preserve the two active owner-handled deals and exclusions. Do not treat EAP applicants or unknown-fit records as warm conversations. Research gaps in the existing cohort can be worked without new outbound approval. Keep new candidates outside an approved outreach/import cohort until the relevant scope exists. Do not replace the read-only strategy document.

Maintain company/sales/funnel-state.json with checkedAt, scopedSources, cohortCounts (or explicit incomplete coverage), selectedOpportunity/task, nextAction, owner, dueOrRecheckAt, actualChanges, evidenceLinks, activeAssignment IDs, CRM readback and Todoist readback. Preserve source URLs and previous valid checkpoints on failure. Reconcile current-work.json with verified current state instead of repeating stale waiting-for-go text. Do not create artificial tasks or counts to demonstrate activity.

Save compact receipts and created record/task IDs in the company workspace as each mutation succeeds. Connector workbench files and session variables can disappear between turns; they are not durable checkpoints. After interruption, recover saved IDs and read back those records before recreating work. Dispatch a ready research batch before unrelated further discovery; persist its assignment ID so another run can continue it.

Update the existing Todoist parent after substantive progress with the actual result, artifact/CRM link, next action, owner and real dependency. Preserve its user text, dates and task identity; read back the update. Reuse or add one task only for genuinely missing authorized work, after checking for duplicates. Do not complete an outreach or funnel-building task because its preliminary list was checked. Keep unchanged waiting state private; no new prospect conversation just to announce no reply.

A useful run ends with a verified change or an active bounded assignment and independent work already completed. If no work can proceed, identify the precise attempted next step and source-backed blocker for each plausible current candidate. Do not invent work or ignore a STOP. After the same concrete action fails twice, try one legitimate alternate tool/source or focused internal handoff and record the result; do not spin or reset the entire batch. New spending, sends, meetings, invitations or commitments still need their scoped authority. Preparation must be finished before asking for a send decision.
